# 0LD_SCH00Ls_SWU_TEMPLATE
A template for making your custom Star Wars Unlimited cards!

Make sure you have the 'Barlow Condensed' font and Inkscape (or other SVG editor) installed.

Click on the object that you want to add to your card and set the X and Y coordinates to (0,0) to add them to your card

For text, edit the chosen text type, then drag it over the card until it looks right
